# Development Roadmap

This roadmap outlines the sequential build order for LocalPages.ph.

## Phase 1: Foundation
- Project structure setup (Next.js, Tailwind CSS).
- Firebase project initialization.
- Firebase Authentication setup.
- User roles configuration.
- PostgreSQL schema implementation.
- Firebase Data Connect setup.
- Basic protected routing framework.

## Phase 2: Business Portal
- Business account dashboard creation.
- Business listing submission forms.
- Save draft functionality.
- Submit for approval workflow.

## Phase 3: Admin & Moderation CMS
- Admin backend scaffolding.
- Pending listings queue.
- Approve/reject/request revision workflows for moderators.
- User management tools.

## Phase 4: Public Interface
- Public homepage development.
- Global search bar component.
- Search filters (category, location).
- Approved business listing display.
- Search results pagination.

## Phase 5: SEO & Discoverability
- SEO-optimized business profile pages.
- City and Category landing pages.
- Dynamic XML sitemap generation.
- `robots.txt` configuration.
- LocalBusiness JSON-LD schema injection.

## Phase 6: AI Readiness & Optimization
- Structure optimization for AI search crawlers.
- IndexNow implementation.
- Google Search Console / Bing Webmaster integration support.
- Core Web Vitals and performance optimization.
